# CULTURA — Explore Humanity (State Atlas Edition)

A responsive cultural discovery website built with HTML, CSS, JavaScript and Three.js.

## What's included
- Interactive 3D Earth on the home page (requires WebGL and internet access).
- Culture profiles for selected countries.
- An India atlas with all 28 states and 8 union territories listed in the project data.
- Search across region names, capitals, festivals, food, arts and descriptions.
- Individual state/territory story pages with cinematic photo headers, animated cultural story cards, quick facts and previous/next region navigation.
- Distinct photo-tile styling, staggered entrances, decorative motifs, hover depth, responsive layouts and reduced-motion support.

## Run locally
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension, or use any local static web server.
4. Open `index.html` through the local server.

The page imports Three.js from a CDN and loads photos/fonts/textures from external services, so an internet connection is needed for the complete visual experience. Some regional photographs are illustrative and may not be an exact photo of the named state; cultural summaries are introductory rather than exhaustive.

## Main files
- `index.html` — page structure
- `style.css` — responsive design and animations
- `script.js` — culture data, navigation, search, state pages and 3D Earth
